# 🚀 Startup Analytics Dashboard

An interactive Streamlit dashboard for analyzing startup funding, valuation, revenue, and business performance.

---

## 📊 Features

* Interactive KPI Cards
* Startup Funding Analysis
* Revenue vs Valuation Analytics
* Industry-wise Performance
* Region-wise Analysis
* Business Insights
* Interactive Plotly Charts
* Dataset Filtering
* CSV Download Option

---

## 📂 Dataset Columns

| Column Name            | Description          |
| ---------------------- | -------------------- |
| Startup Name           | Company Name         |
| Industry               | Startup Sector       |
| Region                 | Geographic Region    |
| Funding Amount (M USD) | Total Funding Raised |
| Revenue (M USD)        | Annual Revenue       |
| Valuation (M USD)      | Company Valuation    |
| Employees              | Number of Employees  |

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/startup-analytics-dashboard.git
cd startup-analytics-dashboard
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
